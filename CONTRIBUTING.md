# Contribuição

Abra uma issue com contexto, reprodução e resultado esperado antes de propor mudanças grandes.
Use dados fictícios, mantenha alterações focadas e rode as verificações do README.
Nunca inclua credenciais, banco de dados, fotos, logs ou dados de clientes em commits/issues.
Relatos de vulnerabilidade devem seguir SECURITY.md. A licença autoral não concede
permissão geral de redistribuição; combine o escopo de contribuições com o mantenedor.
