# Segurança

Não publique vulnerabilidades acompanhadas de credenciais ou dados pessoais em issues.
Use o recurso privado de relato de vulnerabilidades do GitHub, se estiver disponível;
caso contrário, solicite pelo perfil do mantenedor um canal privado, sem incluir detalhes sensíveis.

Esta é uma publicação de portfólio em desenvolvimento. HTTPS, configuração de segredos,
backup e revisão de permissões são responsabilidades de quem implanta o código.
As demonstrações usam apenas exemplos fictícios e não se conectam aos bancos do autor.
